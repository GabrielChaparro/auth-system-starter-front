## Full Description

AuthKick helps developers launch a working self-hosted authentication service without spending days configuring Keycloak from scratch.

It packages Keycloak, PostgreSQL, Docker Compose, a REST auth API, OpenAPI docs, Swagger UI, Postman collection, realm templates, and an isolated E2E smoke test.

You can consume the API from any stack: Next.js, React, Vue, Angular, Laravel, Django, Rails, Spring Boot, Node.js, mobile apps, internal tools, or SaaS products.

This is an early beta release for builders who want a practical starting point for self-hosted auth.

Included:

- Keycloak 24 + PostgreSQL with Docker Compose
- REST authentication API
- Login, refresh token, revoke token, and logout endpoints
- User creation, user update, password update/reset, and role assignment endpoints
- Admin-only authorization for management endpoints
- OpenAPI docs and Swagger UI
- Postman collection and environment
- Environment-driven realm generation
- Isolated E2E Docker stack
- Smoke test script for release validation
- Source code for customization
- 3 months of beta updates

Use it with:

- SaaS products
- Web apps
- Mobile apps
- Internal tools
- Microservices
- Admin panels
- Client projects
- Any app that can call a REST API

Not included yet:

- Hosted service
- Production deployment automation
- Frontend login example
- Kubernetes manifests
- Enterprise support SLA
- Security audit

Beta note:

This is a developer-ready auth API starter, not a managed auth platform. You should review credentials, CORS, redirect URIs, service account permissions, token settings, rate limiting, and production deployment details before using it in production.
